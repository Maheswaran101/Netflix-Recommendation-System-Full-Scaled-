# Netflix-Recommendation-System-Full-Scaled

A personalized movie recommendation engine using collaborative filtering and content-based techniques, built to demonstrate real-world data science skills in Python. This project showcases model evaluation, business insight generation, and dashboard-ready outputs for portfolio and interview readiness.

## 📌 Project Overview

This project aims to replicate the recommendation logic behind platforms like Netflix by analyzing user preferences and movie metadata. It combines collaborative filtering (user-item interactions) and content-based filtering (movie features) to generate tailored suggestions.

## 🧠 Key Features

- Collaborative Filtering using Surprise’s SVD algorithm
- Content-Based Filtering using TF-IDF and cosine similarity
- Hybrid Recommendations for improved personalization
- Evaluation Metrics: RMSE, MAE, precision@k, recall@k
- Business Insights: genre popularity, user engagement, recommendation diversity
- Dashboard-ready CSV outputs for Power BI

## 🛠️ Tech Stack

- Python (Pandas, NumPy, Scikit-learn, Surprise)
- Jupyter Notebook
- Power BI (for dashboard visualization)
- Matplotlib & Seaborn (for EDA and plots)
